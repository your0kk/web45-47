## Описание

Многостраничный интерфейс веб-приложения для ресторана, выполненный на React, TypeScript, React Router и Tailwind CSS.

Реализовано:

- главная страница ресторана;
- страница меню с фильтрацией блюд по категориям;
- добавление товаров в корзину;
- управление количеством позиций в корзине;
- страница оформления заказа;
- модальное окно подтверждения заказа;
- страница «О ресторане»;
- глобальное состояние корзины через React Context и кастомный хук `useCart`;
- комментарии в основных файлах проекта.

## Запуск проекта

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run start
```
